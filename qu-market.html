Deployment method

Metodo de despliegue

  1. Inventory: import IPs, remove duplicates and classify valid/invalid targets.
  2. Inventario: importar IPs, eliminar duplicados y clasificar objetivos validos/invalidos.
  3. Scope: match endpoint count against the purchased package and escalate 1000+ to a consultant.
  4. Alcance: comparar endpoints contra paquete comprado y escalar 1000+ a consultor.
  5. Identity: QuIdentify/Okta validates the deployment owner and role.
  6. Identidad: QuIdentify/Okta valida propietario del despliegue y rol.
  7. Security: QuFense issues the PQC/QRNG-ready policy profile and QuVault protects secrets.
  8. Seguridad: QuFense emite perfil PQC/QRNG-ready y QuVault protege secretos.
  9. Provisioning: QuHub delivers connector configuration and deployment instructions.
  10. Aprovisionamiento: QuHub entrega configuracion de conectores e instrucciones.
  11. Activation: QuAudit records evidence, QuSOC receives telemetry hooks and Aggy remains as guided support.
  12. Activacion: QuAudit registra evidencia, QuSOC recibe telemetria y Aggy queda como soporte guiado.

Self-service deployment protocol

Protocolo de deployment autogestionado

  1. Register: customer authenticates with QuIdentify / Okta before quotes, downloads or purchase.
  2. Registro: el cliente se autentica con QuIdentify / Okta antes de cotizar, descargar o comprar.
  3. Quote: submit the selected scope and receive a tailored commercial proposal.
  4. Cotización: envía el alcance seleccionado y recibe una propuesta comercial personalizada.
  5. Payment: QuPay opens the Stripe checkout only after identity is verified and QuFense policy permits the transaction.
  6. Pago: QuPay abre Stripe Checkout solo despues de verificar identidad y aprobar politica QuFense.
  7. Fulfillment email: QuHub sends the order receipt, technical sheets, certificates, install guides and deployment manifest automatically.
  8. Correo de entrega: QuHub envia automaticamente recibo, fichas tecnicas, certificaciones, guias y manifiesto.
  9. Activation: the email contains a time-bound activation link. Ephemeral API keys are retrieved after Okta re-authentication through QuVault, not exposed in plain email.
  10. Activacion: el correo contiene enlace temporal. Las llaves API efimeras se recuperan tras reautenticacion Okta desde QuVault, no se exponen en correo plano.
  11. Install: Aggy guides the customer through connector setup, endpoint agent installation, SIEM/SOC hooks and verification tests.
  12. Instalacion: Aggy guia conectores, agente endpoint, ganchos SIEM/SOC y pruebas de verificacion.
  13. Evidence: QuAudit stores purchase, identity, policy, installation, key-ceremony and activation evidence.
  14. Evidencia: QuAudit guarda evidencia de compra, identidad, politica, instalacion, ceremonia de llaves y activacion.
